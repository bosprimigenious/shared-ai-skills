# 时间轴、出处与线索问题

本文件对照 Look-Tongji 的时间轴、ClassCorpus 的课堂证据边界、康奈尔笔记的 cue 列。硬规则以 `SKILL.md` 为准。

## 时间轴（2.1）

合格：每一行有定位、阶段名、对应 3.x。

```
定位｜课堂阶段｜对应小节
00:00–04:10｜贸易摩擦引入｜3.1
04:10–09:00｜无政府与相互依赖｜3.2
09:00–12:40｜重复博弈与制度｜3.3
12:40–14:00｜相对收益插叙｜3.4
```

不合格：只有「先讲案例再讲定义」这种无法点回小节的句子；或时间轴写了 3.6 但正文没有 3.6。

## 主张级出处

合格：标题下一行写来源，关键结论后再标一次。

```
### 3.2 无政府与相互依赖
本节问题：相互依赖为何不能单独推出合作？
来源：P013–P028

无政府指缺少强制执行契约的中央权威（P016）。相互依赖提高欺骗成本，但不等于合作自动出现（P022）。
```

不合格：标题写成 `### 3.2 无政府（P013）`；或把只出现「合作」一词的 P040 标成该定义的出处。

冲突时两边都标：`联盟被说成稳定器（P051）；随后又被说成可能放大冲突（P070）。`

【补充背景】写在课堂证据之外，不和 P 号混成同一句「课堂已经证明」。

## 线索问题

合格：问关系，不贴标签。

- 本节问题：无政府状态下重复博弈如何降低欺骗？
- 本节问题：相对收益在何种条件下压过绝对获益？

不合格：`本节问题：重复博弈`（名词，不是问题）；文末再列 20 道闪卡。

第 1 节 2–3 句要义相当于康奈尔的 summary；不要再写第三份结构散文。
