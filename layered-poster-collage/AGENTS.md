# Layered Poster Collage

> 把多张竖版海报或图片排成有真实纸张层次的横版或竖版叠放海报，并优先保留原图文字与像素。适用于“三张在上、若干张压在下面”、指定某张置顶、卡片扇形展开、杂志目录式拼贴；不用于需要模型重绘每张原图内容的创意合成。

## 核心原则

把“生成氛围”和“放置原图”分开。原图含中文、数字、标志或必须保持的细节时，不让图像模型重绘整张卡片；用确定性图像合成保留原像素，只生成或绘制背景、纸边、阴影、旋转和层次。

## 工作流

1. 清点输入图，记录路径、顺序、像素尺寸和方向；缺图要明确报告，不虚构占位图。
2. 从用户描述提取三类关系：`front` 是上层主卡，`back` 是压在下面的卡，`topmost` 是最后绘制、视觉上最高的卡。
3. 默认确定性合成：横版 3840×2160，竖版 2160×3840；保持原图纵横比，不裁主体；先绘制 `back`，再绘制 `front`，最后绘制 `topmost`。
4. 用暖白纸边、柔和投影和小角度旋转制造纸张感。卡片必须实际重叠，不能排成互不接触的两排。
5. 可以用图像模型生成无字背景或纸张氛围，但最终把原图作为独立卡片确定性贴回。模型失败、超时或参考图数量受限时，不重复整图重绘，切换到本地合成。
6. 普通场景运行 `scripts/compose_layered_posters.py`。只有用户要求复杂透视、撕纸、手持或真实摄影环境时，才把模型生成作为主路线。

## 运行脚本

```bash
python3 scripts/compose_layered_posters.py \
  --inputs image1.png image2.png image3.png image4.png image5.png image6.png \
  --front 1 2 3 --back 4 5 6 --topmost 2 \
  --orientation landscape --output poster.png
```

编号按 `--inputs` 的一基顺序解释。`--front` 与 `--back` 必须覆盖全部输入且不得重复；`--topmost` 必须属于 `--front`。

## 排版判断

- 三张主卡：中心卡最大，两侧各旋转约 4°–8°；`topmost` 居中并最后贴入。
- 底层卡：缩小至主卡的约 70%–82%，从左右和下方露出，至少保留能识别主题的一块区域。
- 背景：优先深色、低对比、少纹理；颜色从原图主色提取或采用深蓝黑与轻微暖光。
- 纸边：宽度约卡片短边的 2%–4%，避免纯白刺眼；阴影方向统一。
- 留白：横版避免卡片顶到四边；竖版避免中间出现明显断层。

## 验收

- 解码输出并核对目标像素尺寸、格式和色彩模式。
- 逐张确认输入图都出现一次，没有重复、遗漏或额外卡片。
- 目视确认 `topmost` 遮挡其他主卡，所有 `back` 被主卡压住且仍有可识别区域。
- 原图内文字没有被模型改写；若输出缩放导致小字不可读，只描述为缩放限制，不声称文字已修复。
- 检查旋转后四角未意外出界，纸边、阴影没有被裁断。
- 用户要求成品时，把最终文件放到用户指定目录或项目 `outputs/`，并报告绝对路径和尺寸。

## 停止条件

- 输入图片缺失或无法解码时停止最终合成，列出具体缺失项。
- 不用模型猜测或补写原图中的中文、数字、邮箱和品牌文字。
- 不把参考拼板当成最终海报。
- 图像生成服务连续两次出现同类网络错误后，停止盲目重试，改走确定性合成或明确报告阻塞。
